## Page 3

1 ОБЩАЯ ИНФОРМАЦИЯ      1.1 Диапазоны значений      У каждого тахометра есть 3 диапазона значений. В зависимости от номера  зоны, в которую попадает текущее значение тахометра, выбирается группа  подсказок.   В каждой группе есть 3 подсказки.   Подсказка внутри группы выбирается путем деления диапазона на кол­во  подсказок(получаем 3 поддиапазона).   В зависимости от того, в какой поддиапазон попадает значение тахометра,  выбирается соответствующая подсказка.      1.2 Веса тахометров      Каждый тахометр имеет вес. Данное значение используется при расчете  общего тахометра “Финансовое состояние”. Параметр веса тахометра выступает  как коэффициент (множитель) для расчета, как значение конкретного тахометра  влияет на финансовое состояние в целом.      1.3 Используемые данные      Для расчета значения каждого тахометра, используются опеределенные  группы данных пользователя. Используемые данные указаны для каждого  тахометра отдельно, в разделе ”Формулы”. В случае если необходимых данных  нет, используются стандартные значения указанные в разделе ”Формулы”, для  каждого из тахометров. Такая ситуация возможна, если пользователь недавно  зарегестрировался или какое­то время не вносил данные на свою учетную запись.

2 ФОРМУЛЫ      2.1 Деньги      Вес тахометра: 35.  Диапазоны значений:  1) 0­2;  2) 2­5;  3) 5­6.  Данные:  1) Баланс денег = сумма балансов по денежным счетам(1, 2, 5, 15, 16) +  по кредиткам(8, у которых баланс > 0) в валюте по умолчанию;  2) Расходы: (Все расходы за 3 месяца(от текущей даты) + выплаты по  кредитам за 3 месяца(от текущей даты, переводы на счета типов 7, 8,  9)) / 3.  Расчет:   1) если Баланс денег = 0, то Значение тахометра = 0;  2) если Расходы = 0, то Значение тахометра = 6;  3) Значение тахометра = ((Баланс денег / Расходы) / 6) * 100.

2.3 Долги      Вес тахометра: 15.  Диапазоны значений:   1) 0­30;  2) 30­60;  3) 60­100.  Данные:   1) Выплаты по кредитам за месяц (от текущей даты, переводы на счета  типов 7, 8, 9);  2) Доходы за 1 месяц (доходные операции).  Расчет:   1) если Выплаты по кредитам за месяц = 0, то Значение тахометра = 100;  2) если Доходы за 1 месяц = 0, то Значение тахометра = 0;  3) Значение тахометра = (1 ­ (1 ­ Выплаты по кредитам за месяц /  Доходы за 1 месяц) ) * 100.

2.4 Доходы      Вес тахометра: 30.  Диапазоны значений:   1) 0­5;  2) 5­10;  3) 10­20.  Данные:   1) Доходы за 3 месяца (доходные операции);  2) Расходы: (Все расходы за 3 месяца(от текущей даты) + выплаты по  кредитам за 3 месяца(от текущей даты, переводы на счета типов 7, 8,  9)).  Расчет:   1) если Доходы за 3 месяца = 0, то Значение тахометра = 0;  2) если Расходы = 0, то Значение тахометра = 20;  3) Значение тахометра = ((Доходы за 3 месяца / Расходы ­ 1) * 500.

2.5 Финансовое состояние      Веса тахометров:  1) Деньги ­ 35;  2) Бюджет ­ 20;  3) Долги ­ 15;  4) Доходы ­ 30.  Диапазоны значений:   1) 0­100;  2) 100­200;  3) 200­300.  Расчет:   Взвешенное значение тахометра = (индекс зоны + ((Полученное  значение ­ левая граница диапазона) / (правая граница диапазона ­ левая граница  диапазона))) * вес тахометра;  Значение тахометра = (Сумма взвешенных значений тахометров / 3).
